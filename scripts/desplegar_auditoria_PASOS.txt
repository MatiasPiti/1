===========================================================

PASO 1 - Traer el codigo y correr las pruebas

    cd "C:\Users\Usuario\Desktop\proyecto para el leo\Otter_final\SistemaDual-src"

    git pull origin main

    venv\Scripts\pip install -r requirements.txt

    venv\Scripts\python tests\correr_todos.py

  Si git pregunta "Unlink of file ... failed. Should I try
  again? (y/n)", contesta n todas las veces: el codigo ya
  bajo (lo dice la linea "Fast-forward").

  Tienen que dar 32 en verde. Tarda unos 4 minutos: no uses
  la PC mientras corre. Si la unica en rojo es
  test_config_atomico.py, segui: es la que ya conocemos (en
  Windows falla con la maquina cargada). Si es cualquier
  otra, frena.


PASO 2 - Compilar
  Antes, cerra cualquier .exe que hayas abierto desde dist\.

    build\build_all.bat

  Al final tiene que decir "ApiCelular: autoprueba OK".
  Despues confirma que las 11 apps tienen fecha de hoy:

    dir dist\*\*.exe | Sort-Object LastWriteTime | Select-Object LastWriteTime, Name


PASO 3 - Copiar al pendrive principal
  Primero mira que letra agarro:

    Get-Volume | Where-Object DriveLetter | Select-Object DriveLetter, FileSystemLabel

  Pone esa letra en la primera linea y pega el bloque entero:

    $u = "E:"; $fallo = $false
    foreach ($app in "OtterActualizador","MaestroCaja","MaestroDueno","StockService","DuenoRemoto","ApiCelular","OtterBlindaje","USB_Mantenimiento") {
        robocopy "dist\$app" "$u\$app" /MIR /MT:16 /NFL /NDL /NJH /NP | Out-Null
        if ($LASTEXITCODE -ge 8) { Write-Host "FALLO: $app ($LASTEXITCODE)" -ForegroundColor Red; $fallo = $true } else { Write-Host "OK: $app" -ForegroundColor Green }
    }
    if ($fallo) { Write-Host "HUBO ERRORES - no vayas al local" -ForegroundColor Red } else { Write-Host "Todo copiado" -ForegroundColor Green }

  Tienen que salir las 8 en OK. Si en el paso 2 ApiCelular no
  paso la autoprueba, sacalo de la lista antes de pegar.

PASO 16 - Reemplazar solo el programa
  Esto no toca la base del pendrive, su config.ini ni sus
  exportaciones. NUNCA uses /MIR contra la raiz del pendrive:
  borraria todo lo que no viene en dist\.
  Desde la carpeta del repo, en la primera linea pone la
  letra del pendrive de la Caja y pega el bloque entero:

    $u = "F:"; $app = "USB_Caja"
    if (Test-Path "$u\$app.exe") {
        robocopy "dist\$app\_internal" "$u\_internal" /MIR /MT:16 /NFL /NDL /NJH /NP | Out-Null; $a = $LASTEXITCODE
        robocopy "dist\$app" "$u\" "$app.exe" /NFL /NDL /NJH /NP | Out-Null; $b = $LASTEXITCODE
        if ($a -ge 8 -or $b -ge 8) { Write-Host "FALLO ($a, $b)" -ForegroundColor Red } else { Write-Host "OK: $app actualizado" -ForegroundColor Green }
    } else { Write-Host "En $u no esta $app.exe: ese no es el pendrive de $app" -ForegroundColor Red }

  Despues repeti con el pendrive del Dueno, cambiando la
  primera linea a:   $u = "<letra>"; $app = "USB_Dueno"
