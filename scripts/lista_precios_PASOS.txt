===========================================================
 PASO 2 - COPIAR AL PENDRIVE
===========================================================
Primero, que letra agarro el pendrive (no siempre es E:):

    Get-Volume | Where-Object DriveLetter | Select-Object DriveLetter, FileSystemLabel

Cambiar E: por la letra que sea y pegar TODO el bloque:

    $fallo = $false
    foreach ($app in "OtterActualizador","MaestroCaja","MaestroDueno","StockService","DuenoRemoto","ApiCelular","OtterBlindaje","USB_Mantenimiento") {
        robocopy "dist\$app" "E:\$app" /MIR /MT:16 /NFL /NDL /NJH /NP | Out-Null
        if ($LASTEXITCODE -ge 8) { Write-Host "FALLO: $app ($LASTEXITCODE)" -ForegroundColor Red; $fallo = $true }
        else { Write-Host "OK: $app" -ForegroundColor Green }
    }
    if ($fallo) { Write-Host "`nHUBO ERRORES - no vayas al local" -ForegroundColor Red }
    else { Write-Host "`nTodo copiado" -ForegroundColor Green }

Tres cosas de ese bloque:

  - /MIR borra en el destino lo que no esta en el origen,
    para que no queden restos de la version vieja. Apunta a
    E:\<app> carpeta por carpeta, NUNCA a E: suelto.

  - robocopy devuelve 1, 2 o 3 cuando salio BIEN. El error
    recien empieza en 8. Por eso el chequeo es >= 8.

  - Un "Write-Host Listo" al final SIEMPRE dice Listo,
    aunque robocopy haya fallado: por eso el chequeo va
    adentro del bucle.

Llevar tambien la carpeta scripts\ (para el blindaje).
